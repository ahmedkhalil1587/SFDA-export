# مشروع قائمة أدوية SFDA

نظام يسحب قائمة الأدوية البشرية المسجلة من موقع الهيئة العامة للغذاء والدواء
تلقائيًا كل شهر، ويعرضها كملف Excel جاهز للتحميل من خلال صفحة ويب.

## هيكل الملفات

```
├── index.html                          # الصفحة اللي فيها زرار التحميل
├── sfda_drugs_scraper.py               # سكريبت السحب (بايثون)
├── requirements.txt                    # المكتبات المطلوبة
├── data/
│   ├── SFDA_Drugs_latest.xlsx          # آخر نسخة (نفس الاسم دايمًا، الرابط في index.html بيشاور عليه)
│   └── SFDA_Drugs_2026-09-09.xlsx      # نسخة بتاريخ كل عملية سحب (أرشيف)
└── .github/
    └── workflows/
        └── scrape-drugs.yml            # الجدولة التلقائية (GitHub Actions)
```

## خطوات التفعيل على GitHub

### 1) إنشاء الريبو ورفع الملفات
- اعمل ريبو جديد على GitHub (Public لو عايز GitHub Pages يشتغل مجانًا).
- ارفع كل الملفات دي بنفس الهيكل اللي فوق (بالـ Git أو بالسحب والإفلات على GitHub.com).

### 2) تفعيل GitHub Pages
- من إعدادات الريبو (Settings) → Pages.
- من "Branch" اختار `main` والمجلد `/ (root)`.
- احفظ، وهيديك رابط زي: `https://username.github.io/repo-name/`

### 3) تفعيل GitHub Actions (السحب التلقائي)
- الملف `.github/workflows/scrape-drugs.yml` مبرمج يشتغل تلقائيًا أول كل شهر.
- لو عايز تشغّله يدويًا أول مرة (عشان تتأكد إنه شغال): روح تبويب "Actions" في الريبو،
  اختار "Scrape SFDA Drugs List" من الشمال، دوس "Run workflow".
- أول تشغيلة هتاخد حوالي 10-15 دقيقة (بيسحب 454 صفحة).
- بعد ما يخلص، هتلاقي ملف جديد اتضاف في مجلد `data/` تلقائيًا.

### 4) التأكد إنه شغال
- افتح رابط GitHub Pages بتاعك، ولازم تلاقي زرار "تحميل آخر نسخة" شغال ويحمّلك الملف.

## ملاحظات مهمة

- **معدل السحب:** السكريبت بيستنى نص ثانية بين كل طلب والتاني عشان مايتحظرش من حماية الموقع (WAF).
  لو حصل حظر مؤقت، جرب تزود وقت الانتظار في السكريبت (`REQUEST_DELAY_SECONDS`).
- **الجدولة:** حاليًا مظبوطة شهريًا (أول كل شهر). لو عايزها أسبوعيًا أو يوميًا، غيّر سطر
  `cron` في ملف `.github/workflows/scrape-drugs.yml`.
- **تسجيل الدخول والصلاحيات:** GitHub Pages بيستضيف صفحات عامة بس (مفيهاش تسجيل دخول حقيقي).
  لو عايز صفحة فيها يوزرات وصلاحيات فعلية، هتحتاج تنقل الاستضافة لخدمة فيها Backend
  حقيقي (زي Vercel + قاعدة بيانات، أو Firebase Auth) في مرحلة تالية.
